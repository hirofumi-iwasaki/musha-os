# v0.2.0 公開候補ノート

状態: 未公開・実機承認待ち。v0.1.0の実機合格をこの候補へ引き継がない。

## 追加機能

- FAT32に加え、exFATのUSBデータ媒体を読出し専用で扱う。
- ルートのファイル一覧から外付けキーボードで選択し、256バイトずつ16進数とASCIIを表示する。
- 前後のページ移動、一覧への復帰、待機中の取消し、空ファイルとエラーの表示。
- 長い名前の全体確認と、非ASCII文字の代替表示。
- 入力とストレージが別xHCI controllerでもファイル読出しを継続する。

## 操作と制限

上下で選択、Enterで開く、Page Up／Downでページ移動、Escで一覧、Qで終了。
通常版は従来の診断画面からファイルビューアーへ変更する。
詳しくは [操作説明](file-viewer.md)。

ルート最大128ファイル、1ファイル64MiB、1ページの読出し10秒。
後方移動は先頭から読み直すため、大きなファイルでは時間制限に達する場合がある。
日本語の字形描画、サブディレクトリー、書込み、編集、再接続による自動復帰は未対応。
内蔵キーボード・Touch Bar・トラックパッドは未対応。外付けUSB Boot Keyboardが必要。
QEMUの通信回帰は実機NIC対応を意味しない。exFATからの直接起動も対象外。

## 候補の内容

通常EFI、64MiBのQEMU起動イメージ、合成exFAT試験イメージと既知ファイルのハッシュ、
ライセンス、操作資料、manifest、SHA256SUMSを同梱する。
64MiB像はQEMU用であり、物理USBへそのまま配布・書込みする手順ではない。
物理媒体は正確な容量に合わせた既存の [USB準備手順](usb-install-macos.md) を使う。

合成exFAT像は検証用。日常の媒体には標準フォーマッターを使用し、
既存データを保全したうえで専用のテスト媒体で確認する。
検証結果と残件は [工程7記録](release-validation-0.2.0.md)、実機の手順は
[受入試験](hardware-acceptance-0.2.0.md) に記載する。

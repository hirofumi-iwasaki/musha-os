Status: record (2026-10-12)

状態: 全項目未実施。対象はMacBook Pro 2018と動作確認済みのLenovo有線キーボード。
内蔵キーボードの動作は必須条件に含めない。

候補のmanifestに記載されたcommit・EFI SHA-256を記録し、試験するEFIと照合する。
USBの型番、容量、接続ポート、ハブ、macOS側のファイル名・サイズ・SHA-256も記録する。
今回の作業では物理USBへ書き込んでいない。候補に含む64MiB像はQEMU用。

最初にFAT32構成で通常候補の一覧と操作を確認し、次にexFATデータ媒体へ進む。
起動用FAT32とデータ用exFATの選択は最初に利用可能な媒体を採用する現在の制約に従う。
複数の読める媒体がある場合、exFATが選ばれる保証はない。画面の形式表示を必ず確認する。
今回のQEMUではFAT起動をSATA、データをUSBへ分離して検証している。
実機でFAT32が先に選ばれる場合はその構成を記録し、媒体選択を解決するまでexFAT試験を合格にしない。

Q終了後はセッション終了案内になる。通常版で従来のAPP COMPLETEやキーコード表示は要求しない。
写真だけではDMA停止を証明できないため、QEMUの停止検証と実機で観測できた挙動を分けて記録する。
実機が使えるようになった時点で結果を別の記録ファイルへ保存し、未実施を実測結果に置き換える。
